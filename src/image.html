Расстояние по фото (3 маркера)
Фокус в пикселях исходного изображения. Оптический центр — центр кадра; изображение без дисторсии.
Калибровка по известным XYZ →
Углы камеры неизвестны. Высота отбирает подходящие решения, но не заменяет измерения по фото.
P1 = (0, 0, 0). +X: от P1 к P2. +Y: перпендикулярно X по земле в сторону P3. +Z: вверх. Эта позиция не используется при расчёте по фото.
Вид перед маяками: голубой слева, розовый за жёлтым. X = 0, Y = −200, Z = 50 — камера в 200 м перед жёлтым на высоте 50 м.
Жёлтый маяк должен быть в центре исходного кадра. Для расчёта используются реальные координаты всех трёх кликов; программное смещение картинки не меняет калибровку.
Камера смотрит на P1. Фантомы — только визуальная проверка, их смещения не влияют на расчёт.
Поворот φ — в кадре вокруг P1 (желтой). Смещения ΔX/ΔY — в пикселях.
f(px) = f(мм) / ширина сенсора(мм) × ширина кадра(px). Для эквивалентного фокуса используйте эквивалентную ширину сенсора.
σ = 0 px
Автопоиск: жёлтый P1, синий P2, розово-фиолетовый P3 на сером фоне. Или кликни по центрам маркеров вручную.
Зум: колесо. Панорама: ПКМ или Shift+drag.
Alt + колесо — размер кольца прицела. Совместите его с краем круглого маяка; пустой центр не закрывает точку выбора.
